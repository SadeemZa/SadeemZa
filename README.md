- 🎓 Currently completing my Computer Science degree at Taif University

## 🛡 Cybersecurity Journey

> Security is not only about finding what is wrong—it is about understanding the system well enough to help protect it.

My current direction is defensive security: learning how network activity behaves, how to investigate it, and how security teams use evidence to make better decisions. I am also developing a careful foundation in security testing, always with a focus on ethical and authorized practice.
